Scenario 13. Team Vibe

🔮 MBTI 팀 케미 분석기

팀원들의 MBTI를 입력하면 팀 전체의 케미·강점·갈등 포인트를 분석하고, 협업 팁과 역할 분배 가이드를 제공하는 서비스예요.

"우리 팀이 왜 이럴까?"를 데이터로 이해하고, 더 즐겁게 일하는 방법을 찾는 게 핵심이에요.

Input
팀원 이름 + MBTI (최대 10명), 팀 목표 (프로젝트 협업 / 일상 협업 / 아이디어 회의)
Process
MBTI 조합 분석 + 강점·갈등 포인트 도출
Output
팀 케미 점수 + 강점 분석 + 잠재 갈등 포인트 + 역할 추천 + 협업 팁
팀 정보 입력 & 분석 결과
예시 데이터가 미리 입력되어 있어요. 자유롭게 수정 후 분석해보세요.
왼쪽에서 팀원을 입력하고 "팀 케미 분석하기"를 눌러보세요.
